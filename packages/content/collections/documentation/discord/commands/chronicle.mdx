# `/chronicle` Command

The `/chronicle` command is the administrative interface for managing chronicles (game sessions) linked to this Discord server.

## Permissions

Only authorized Storytellers may access this command.

## Features

- **Chronicle Switching**: Easily toggle between multiple chronicles linked to the server.
- **Default Game Edition**: Configure the default edition for new characters and mechanics (`5th`, `20th`, or `cod`).
- **Storyteller Administration**: Grant or revoke storyteller privileges for users and roles within this chronicle.
- **Chronicle Creation & Deletion**: Create new chronicles or delete old ones (with automatic safeguard reconstitution ensuring at least one chronicle always remains linked to the server).
