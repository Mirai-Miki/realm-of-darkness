# `/guild` Command

The `/guild` command allows server administrators to configure server-wide settings and assign server-wide Storyteller roles.

## Permissions

Only authorized Storytellers may access this command.

## Features

- **Server Storyteller Roles**: Designate Discord roles that automatically confer Storyteller status across all chronicles in this server.
- **Server Overview**: View current server configuration and linked chronicles.
